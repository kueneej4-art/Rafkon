# Сайт «Грузчики и грузоперевозки в Ижевске»

Одностраничный продающий сайт (лендинг) под Яндекс.Директ. Каждая заявка
сразу приходит в Telegram вместе с меткой, из какой рекламы пришёл клиент.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | сам сайт: тексты, калькулятор, 4 формы заявки |
| `privacy.html` | политика конфиденциальности (обязательна по 152-ФЗ и для модерации Директа) |
| `netlify/functions/lead.mjs` | принимает заявку и отправляет её в Telegram |
| `netlify.toml` | настройки хостинга Netlify |
| `YANDEX_DIRECT.md` | план рекламной кампании |

## Как запустить (≈15 минут)

1. **Netlify → Add new site → Import from GitHub** → репозиторий `Rafkon`.
   В поле **Base directory** впишите `gruzchiki`. Остальное оставьте пустым.
2. **Site configuration → Environment variables** — добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather;
   - `TELEGRAM_CHAT_ID` — куда слать заявки (ваш id или id группы менеджеров;
     несколько — через запятую).
   Бот должен хоть раз получить от вас `/start`, иначе Telegram не даст ему написать первым.
   Для группы: добавьте бота в группу, id группы начинается с `-100…`.
3. **Deploy** → откройте сайт, отправьте тестовую заявку → она должна прийти в Telegram.
4. Подключите свой домен (Domain management), HTTPS Netlify выдаст сам.

## Что поменять под себя

Всё в одном блоке `CONFIG` внизу `index.html`: название, телефон, часы
работы, оффер, Telegram/WhatsApp, реквизиты ИП, номер счётчика Метрики и цены
для калькулятора. Цены в карточках услуг и таблице цен — в тексте страницы
(ищите `data-price`). Реквизиты оператора — в `privacy.html`.

## Яндекс.Метрика (обязательно для Директа)

1. Создайте счётчик на metrika.yandex.ru, включите Вебвизор.
2. Впишите номер в `CONFIG.metrikaId`.
3. В Метрике → Цели создайте цели типа **JavaScript-событие** с идентификаторами:

| Идентификатор | Когда срабатывает |
|---|---|
| `lead` | заявка успешно отправлена (**главная цель для Директа**) |
| `phone_click` | клик по номеру телефона |
| `messenger_click` | клик по Telegram/WhatsApp |
| `form_open` | открыли всплывающую форму |

Сделайте составную/комбинированную цель «Все обращения» = `lead` + `phone_click` + `messenger_click`.

## UTM-метки

Сайт запоминает `utm_*` и `yclid` и прикладывает их к заявке: в Telegram будет
видно, по какой кампании и какой ключевой фразе пришёл клиент. Шаблон для ссылок
в Директе:

```
https://ваш-домен.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```
